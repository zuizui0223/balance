# Generality candidate matrix v1

## Purpose

This matrix is the replication layer **after** the first same-system causal chain. It does not treat every literature example as an equivalent replication.

The three universal objects are kept separate:

```text
SCH
shared-coordinate conflict geometry

BALANCE
finite sandwiched occupancy / persistence domain

BITA
functional differentiation / dimensional release under coupling and cost
```

A system can be strong for one chapter and uninformative for another.

Machine-readable matrix:

```text
comparative/GENERALITY_CANDIDATE_MATRIX_V1.csv
```

## Evidence rule

Cells use `NOT_YET_AUDITED` whenever the current repositories do not already support a stronger role. Missing cells are not filled by analogy.

A literature anchor is not promoted to a causal replication merely because its qualitative biology resembles the theory.

## Current ordering

### G0 — Pedicularis rex

Primary causal existence test.

Current package:

```text
SCH
causal design + production analyzer ready; real Experiment A not executed

BALANCE
shared Experiment-B consumer ready in green PR; real worldline not executed

BITA
production x-y release analyzer ready; real Experiment B not executed
```

The point of Pedicularis is not that it is already positive. It is the current system in which the same population × season can, in principle, close all three chapter-specific causal questions.

## G1 — floral replication layer

### Dalechampia

SCH repository role:

```text
strongest existing observational compromise geometry
```

but selective antagonist intervention and reversible multilevel display manipulation remain unresolved.

BITA repository role:

```text
historical functional redeployment / exaptation / addition anchor
```

It is explicitly **not** assigned BITA parameter estimates and is not a causal `R_state` test.

BALANCE direct worldline status is currently `NOT_YET_AUDITED`.

### Castilleja linariaefolia

SCH role:

```text
high-value short-path fallback
```

because opposing pollinator and seed-predator selection and a short antagonist-to-seed-loss path are available, while direct multilevel manipulation and selective predator intervention remain missing.

BALANCE/BITA roles remain unaudited rather than inferred.

### Nicotiana attenuata

SCH describes it as the strongest local shared-cue / SCH→BITA bridge but not the cleanest completed one-coordinate optimum surface.

BITA contains extensive interaction/mechanism work and treats Nicotiana as a high-information interaction/release special-case anchor. The programme chain is explicitly not already complete.

The missing Chapter-2 question is important: direct common-scale `W_S*` versus `W_D*` has not yet been identified merely from the local factorial interaction literature.

### Peucedanum multivittatum

BALANCE:

```text
positive longitudinal selection mosaic
multi-definition HL--HC critical region
no direct matched W_S* / W_D* yet
```

BITA:

```text
natural partial functional differentiation
D1 preferential/differential loading strongly supported
D2 experimental R_state not identified
```

SCH does not currently have the required causal fitness-scale conflict receipt for this system.

Thus Peucedanum is a particularly valuable **observational bridge across Chapters 2 and 3**, not a substitute for Pedicularis causal closure.

## G1 negative / boundary controls

### Ipomopsis aggregata

SCH currently treats it as a near-complete negative / monotonic control. Its role is to test that multifunctionality alone need not generate a stabilizing compromise.

### Platycodon grandiflorus

The flower-angle example is an aligned-optimum control: horizontal orientation improves pollination while also avoiding rain damage. Two functions therefore need not oppose one another.

Under the registered programme logic, absence of a SCH conflict means a BALANCE middle world should not be manufactured merely because two functions exist.

## G2 — broader functional / architectural generality

### Polemonium viscosum

SCH role is a broad pollination-versus-water/physiological-cost conflict candidate. It is valuable precisely because the competing function is not the same pollinator–seed-predator biology as Pedicularis.

Its BALANCE and BITA architecture roles remain unaudited.

### Cichlid oral and pharyngeal jaws

BITA uses this as a cross-domain architecture-state anchor:

```text
function partitioning
+ residual evolutionary/genetic integration
= partial rather than complete differentiation
```

The BITA repository explicitly states that the literature does **not** estimate `s`, `lambda`, `K`, or `Delta_arch`, and does not prove that a measured one-axis compromise caused the historical origin of pharyngeal jaws.

SCH and BALANCE causal roles therefore remain unaudited.

## Replication priority

The matrix does not mean “work down every row.” The current sequence is:

```text
1. close Pedicularis G0 causal chain
2. choose G1 systems that complement the weakest chapter signatures
3. include negative/aligned controls
4. only then promote cross-domain G2 claims
```

Likely high-value complementary pairs after G0 are:

```text
Dalechampia
-> stronger SCH compromise geometry + historical architecture reorganization

Nicotiana
-> strongest local same-cue mechanism bridge

Peucedanum
-> strongest current observational BALANCE transition + natural partial differentiation
```

These are complementary, not interchangeable replications.

## Promotion ceiling

Do not call the programme universal until:

1. at least one same-system causal chain is positive;
2. chapter-specific signatures recur in biologically distinct systems;
3. at least one negative / aligned-optimum control behaves as predicted;
4. direct causal results are separated from observational and historical anchors;
5. the recurrence is of the **mathematical/causal architecture signature**, not one specific pollination–defence mechanism.
