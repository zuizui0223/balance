## Malvaceae

The review explicitly states that Malvaceae contains only **one reported heterantherous species**. This means the representative can be independently resolved if one species is tied unambiguously to pre-2010 heteranthery evidence.

`Sparrmannia africana` remains a discovery candidate because its flower has conspicuous fertile/sterile differentiation, touch-sensitive stamens and pollen-mimic structures. But the accessible evidence does not yet provide the required pre-2010 species-level heteranthery receipt, and the sterile outer set creates a definition conflict.

Current status: no promotable species.

## Bixaceae

The earlier focus on `Cochlospermum vitifolium` is weakened.

Its pollination biology is excellent: pre-2010 work establishes pollen-only reward, poricidal anthers, buzz pollination and quantitative pollen removal/deposition. But a 1981 genus treatment describes `Cochlospermum` stamens as equal, while some regional floras describe longer outer stamens. No functional two-type stamen receipt has been recovered.

The stronger candidate is `Amoreuxia palmatifida`.

Pre-2010 taxonomic treatments distinguish `Amoreuxia` from `Cochlospermum` by stamen morphology. `Amoreuxia` flowers have two stamen sets; the upper/distal stamens are shorter and differently coloured from the lower/proximal stamens. Species-level descriptions of `A. palmatifida` retain this two-set length/colour differentiation and poricidal anthers.

This is strong heteranthery morphology, but it does **not** identify the exact 2010 Table S1 representative because the review does not say Bixaceae contributes only one heterantherous species.

Current strongest candidate: `Amoreuxia palmatifida`, **OPEN pending exact review linkage**.

## Scrophulariaceae

A direct pre-2010 candidate now exists: `Diascia anastrepta`.

Manning & Brothers (1986) explicitly describe marked heteranthery. The anticous anther pair is much reduced and produces little or no yellow pollen; the posticous pair, positioned with the stigma, produces copious grey-green pollen. The same work directly observes the oil-collecting bee pollinator.

Unlike `Agalinis` or `Pedicularis`, `Diascia` is compatible with APG-III Scrophulariaceae.

However, the review does not state that Scrophulariaceae contains only one heterantherous species, and the main-text reference list does not uniquely bind `D. anastrepta` to the Table S1 representative.

Current strongest candidate: `Diascia anastrepta`, **OPEN pending exact review linkage**.

## Strengthened selection rule

A candidate can become the canonical representative only by:

1. exact Supporting Table S1 linkage; or
2. all of:
   - secure APG-III family placement;
   - species-level pre-2010 heteranthery evidence;
   - the review explicitly states that the family has only one reported heterantherous species.

This prevents a real heterantherous species from being mistaken for the particular representative chosen by the review.
