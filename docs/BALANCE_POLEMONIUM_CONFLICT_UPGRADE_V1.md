# BALANCE Polemonium conflict-pattern upgrade v1

## Decision

`Polemonium viscosum` is upgraded in the Chapter-2 reality-pattern ledger from `UNRESOLVED` to:

```text
CONFLICT_WITHOUT_SPLITTING
```

This is a **pattern-level upgrade only**. It does not identify direct BALANCE occupancy because the literature does not compare an optimized shared architecture against a registered differentiated/alternative architecture on one matched fitness scale.

The upgrade is based on a same-system programme in which pollination benefit, antagonist/nectar-larceny avoidance and water cost all act on floral phenotype while the plant retains an integrated floral architecture.

---

## Source chain

### Galen 2000 — flower size versus water economy

Galen (2000; *The American Naturalist*; DOI `10.1086/303373`) established the broad physiological conflict background in alpine `P. viscosum`.

Larger floral investment can improve reproductive performance while imposing greater water cost, and watering changes the demographic consequences of floral investment.

Admitted role:

```text
RESOURCE_DEPENDENT_FLORAL_COST
REPRODUCTIVE_VS_PHYSIOLOGICAL_CONFLICT_BACKGROUND
```

This source alone did not justify a positive BALANCE pattern class because it did not resolve a pollinator-antagonist functional contrast or an alternative architecture worldline.

### Galen & Cuba 2001 — direct flower-shape functional conflict

Galen & Cuba (2001; *Evolution* 55:1963-1971; DOI `10.1111/j.0014-3820.2001.tb01313.x`) directly manipulated flower shape.

The key ecological mapping is:

```text
more open / flared funnel flowers
-> better bumblebee pollen receipt / reproductive performance
-> greater accessibility to nectar-thieving ants

more tubular / constricted flowers
-> reduced ant entry
-> reduced pollen receipt and seed set
```

Experimental constriction therefore moves the same floral architecture in opposite functional directions:

```text
ant defence improves
while
pollination performance declines.
```

The study additionally modelled the environment dependence of the defended tubular phenotype. In high-ant-predation conditions the defence benefit can make a tubular phenotype comparatively favourable, whereas in tundra conditions dominated by pollination benefit it is disadvantageous.

Admitted role:

```text
DIRECT_SAME_SYSTEM_FUNCTIONAL_CONFLICT
EXPERIMENTAL_TRAIT_PERTURBATION
COMMON_REPRODUCTIVE_CONSEQUENCE
ENVIRONMENT_DEPENDENT_FUNCTIONAL_WEIGHT
```

Claim ceiling: this is not a direct `W_S*` versus `W_D*` comparison because both manipulated states remain variants of the same integrated flower rather than matched shared and differentiated worldlines.

### Galen et al. 2011 — dosage-dependent chemical defence trade-off

Galen, Kaczorowski, Todd, Geib & Raguso (2011; *The American Naturalist*; DOI `10.1086/657993`) studied floral 2-phenylethanol (`2PE`) in the same species.

The programme recovers a second, mechanistically different form of the same multifunctional conflict:

```text
increased 2PE
-> reduced ant nectar larceny

but at sufficiently high dosage
-> reduced bumblebee visitation / pollination performance.
```

Moderate emission can protect nectar without the full pollination penalty, whereas high emission reveals the cost side of stronger defence.

Admitted role:

```text
DOSAGE_DEPENDENT_POLLINATOR_ANTAGONIST_TRADEOFF
MECHANISTIC_SUPPORT_FOR_PERSISTENT_INTEGRATED_ARCHITECTURE
```

This source is not used as an independent literature replication from the 2001 flower-shape source. Both contribute to one `Polemonium viscosum` system cluster.

## Why the ledger class changes

The prior ledger row used only the Galen 2000 drought result and therefore conservatively recorded:

```text
UNRESOLVED
```

The 2001 experiment materially raises the evidence level because the same plant system now has a direct intervention showing opposing functional consequences of one floral architecture coordinate, including seed-set loss on the pollination side when antagonist resistance is increased.

The 2011 experiment independently shows that stronger floral ant deterrence can also incur a pollination cost through scent dosage.

Together the programme supports:

```text
real multifunctional conflict
+
experimentally perturbed floral phenotype
+
opposed pollinator and antagonist consequences
+
integrated floral architecture persists
```

Therefore the appropriate R-layer pattern class is:

```text
CONFLICT_WITHOUT_SPLITTING
```

---

## Why this is still not direct BALANCE occupancy

The Chapter-2 direct object remains:

```text
L > 0
and
W_D* - W_S* < 0
```

The Polemonium programme does not supply a prospectively registered alternative/differentiated architecture `D` with its own optimized worldline.

Specifically, the literature does not provide:

```text
optimized shared/integrated flower       W_S*
versus
optimized differentiated architecture   W_D*
```

under one matched environment and common fitness scale.

The manipulated tubular and flared flowers are alternative states **within the shared floral architecture**, not a shared-versus-differentiated worldline comparison.

Therefore do not estimate or infer:

```text
rho
Phi
xi
d_B
BALANCE width
```

from these studies.

## Quantitative-stratum consequence

This upgrade changes the qualitative R-layer pattern map but does **not** make Polemonium `effect_size_ready` for the registered `OPPOSING_FLORAL_SELECTION` stratum.

The Galen & Cuba experiment is a manipulated phenotype contrast rather than an immediately compatible bivariate pair of standardized selection gradients:

```text
(beta_pollinator, beta_antagonist)
```

with a joint covariance matrix.

Accordingly the quantitative screening ledger records:

```text
SOURCE_REANALYSIS_REQUIRED
NONSTANDARD_EFFECT_REANALYSIS_REQUIRED
```

A common reanalysis would need the original individual-level treatment/trait/fitness data or enough summary information to map both functional channels to the preregistered estimand with uncertainty.

The 2011 scent-dose experiment is retained as mechanistic support and is not silently combined with the 2001 flower-shape experiment as an independent effect.

---

## Independence contract

Use exactly one literature/system cluster:

```text
Polemonium viscosum
```

The 2000, 2001 and 2011 papers are complementary evidence within that cluster.

Do not count:

```text
three papers
=
three independent BALANCE replications.
```

This preserves the source-level independence rule used throughout the R layer.

## Updated claim allowed

Appropriate:

> In `Polemonium viscosum`, experimental modification of floral architecture and floral chemistry shows that reducing ant nectar larceny can impose pollination and reproductive costs, while drought additionally changes the cost of floral investment. The system therefore provides a strong real-world conflict-without-splitting pattern in an integrated flower.

Not appropriate:

> Existing Polemonium experiments directly demonstrate a BALANCE middle-world reserve or show that an optimized shared architecture outperforms a differentiated alternative.

## Consequence for the programme

Polemonium strengthens the cross-system recurrence result because its conflict differs biologically from the seed-predator examples in `Dalechampia`, `Castilleja` and `Pedicularis`:

```text
Dalechampia / Castilleja / Pedicularis
pollination versus pre-dispersal seed predation

Polemonium
pollination versus ant nectar larceny
plus physiological water cost
```

The recurrent object is therefore broader than one pollination-seed-predator mechanism, while the direct BALANCE claim remains deliberately unpromoted.
