# BALANCE reality-pattern ledger expansion v2

## Scope

This is the first bounded expansion of the Chapter-2 `R` layer beyond the original Peucedanum seed row.

The expansion deliberately uses **already adjudicated sister-repository evidence** before launching a new broad literature search. Its purpose is to establish the bookkeeping rules that prevent a familiar failure mode:

```text
interesting multifunctional example
-> silently promoted to BALANCE evidence.
```

That promotion is not allowed.

The pattern ledger now records an independent biological cluster only at the strongest claim ceiling already supported by the source audit. No row is converted into a direct `W_S* > W_D*` receipt unless a same-context comparable worldline analysis actually exists.

## Why six rows remain UNRESOLVED

The unresolved rows are scientifically useful because each closes one ingredient while leaving the BALANCE-specific ordering open.

### Polemonium viscosum

A real reproductive-benefit versus drought-cost conflict is supported, but no explicit shared-versus-alternative architecture ordering is available.

### Nicotiana attenuata

The programme contains a strong shared receiver conflict and a defence-like second-axis surface, but the required links occur across different experiments. A programme composite is not one common-scale BALANCE worldline comparison.

### Primula farinosa

Pollinator/grazer balance changes morph selection and morph frequencies. This is strong evidence for context-dependent polymorphism and microevolution, but frequency-dependent maintenance is not automatically static BALANCE occupancy and must not be imported from PAYOFF logic.

### Brassica rapa

Herbivory redirects bee-driven multigeneration evolutionary trajectories. This supports functional-weight-dependent evolutionary redirection, not a shared-versus-differentiated architecture fitness ordering.

### Salmonella HisA/TrpF

Bifunctional/generalist and duplicated/specialist outcomes both exist, and duplication can be costly. The experiments do not yet provide one matched background/environment comparison of optimized shared and differentiated architectures.

### Cichlid jaw systems

Functional partitioning with residual integration is an architecture-state anchor. Direct comparable fitness of the shared and differentiated architectures, and the causal conflict path, are not identified.

## Screening controls are separate

`data/BALANCE_PATTERN_SCREENING_CONTROLS_V1.csv` records systems that should **not** enter the positive recurrence numerator:

- Costa Rican Dalechampia — geographic absence/weakening of the Mexican conflict geometry;
- Platycodon grandiflorus — aligned pollination/rain-protection optimum;
- Abelia x grandiflora — multifunctionality without demonstrated opposing optima;
- Ipomopsis aggregata — current near-monotonic/weak-conflict boundary control.

This separation matters because a no-conflict control is not the same thing as a `DIRECT_DIFFERENTIATION` negative case. The latter requires active conflict followed by an identified differentiated outcome with no supported middle regime.

## Current empirical conclusion

The first bounded cross-repository recovery supports a **nontrivial but narrow positive result**:

> Conflict can coexist with an integrated/shared phenotype in multiple independent plant systems, and one additional plant system shows a transition-mosaic signature. However, the present evidence base has not yet recovered a case in which an explicit accessible differentiated alternative is measured and shown to remain inferior, nor a quantitative stratum suitable for pooling.

So the missing observational dimension is no longer vague. It is:

```text
explicit alternative architecture
+
active conflict
+
comparable performance/fitness
+
ordered environmental or architectural context
```

That is the next literature-search target.

## Next retrieval priority

Search should now prioritize studies that can fill the currently empty classes rather than simply adding more multifunctional examples:

1. `PERSISTENT_INTEGRATION_WITH_ALTERNATIVE_AVAILABLE`;
2. `BOUNDARY_CROSSING`;
3. `DIRECT_DIFFERENTIATION`;
4. `HYSTERESIS_OR_PATH_DEPENDENCE`;
5. compatible repeated worldline/fitness definitions for quantitative pooling.

High-value candidate families already registered by the repositories are:

```text
HisA/TrpF and related duplication-specialization experiments
cichlid shared-vs-partitioned feeding architectures
Nicotiana shared-cue plus defence-axis systems
environmental gradients with integrated and differentiated phenotypes
```

The search should stop treating source count as progress. Progress is closure of one of these empty theory-linked pattern classes.

## Claim ceiling

This expansion establishes a reproducible source-adjudicated evidence map. It does not estimate natural prevalence, `s`, `K`, `Phi`, `rho`, `xi`, or `d_B`, and it does not promote any observational row to direct BALANCE occupancy.
