## New ecological discrimination: **where** the conflict operates is not captured by one functional family flag

The original U6 descriptor 'pollen theft' includes biologically nonidentical processes:

1. **Removal before fertilization/export:** pollen consumed in anther before reaching a suitable stigma (thrips, some pollen-collecting bee cases). This can be a male-function pollen-allocation trade-off if measured against successful siring.
2. **Removal after deposition onto a recipient stigma:** *Melastoma affine* honeybees physically remove pollen that another visitor had already deposited. The fitness mechanism includes interruption of female-side pollen receipt, and can be experimentally distinct from competition for source-anther pollen. A direct comparison of different pollen anthers would not automatically address this post-deposition route.
3. **Bee behavioural mode and phase-specific access:** *Impatiens* visitor behavioural states, *Grevillea* male-stage resource collection and bird access, *Campomanesia* ineffective versus effective pollen collectors. These patterns can change function without a genetically new organ.
4. **Mite-mediated pollen plus nectar exploitation:** *Hamelia* flower mites use more than one floral resource; an attractive reward channel is not a demonstrated siring cost or new module.
5. **Different observational timescales:** nighttime thrips feeding and daytime legitimate visits, male versus female flower phases, sequential visits and stigma deposition/removal. The U6 source tag `SIMULTANEOUS` means the original **available resource conflict geometry** under its source screen, **not measured pointwise coincidence of two function-specific optima**.

The first immediate repair is **not** overwriting the frozen `module_substrate` or `conflict_timing_geometry`; it is documenting which *actual biological pollen source, recipient and visitor stage* was measured in the original source, and requiring independent review before using those source tags to estimate an SLK/PAYOFF payoff.

A general phylogenetic macro model should therefore not pool these directly as a single scalar source-pollen competition coefficient. Instead create an independently validated `functional_location` variable distinct from `function_pair`, `timing`, `anatomical_separation`, `reversible_plasticity`, and `heritable_origin`.
