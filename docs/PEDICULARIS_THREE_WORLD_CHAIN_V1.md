# Pedicularis rex three-world validation chain v1

## Purpose

`Pedicularis rex` is the preferred same-species test of whether SCH, BALANCE, and BITA describe adjacent regions of one architecture problem rather than unrelated examples.

The chain is deliberately ordered to avoid circularity.

## Chapter 1 / SCH — shared-coordinate world

Registered shared coordinate:

```text
z = realized corolla exsertion above the cupulate bract.
```

SCH manipulates:

```text
z
P = pollination dependence
G = independently qualified seed-predator exposure
```

while the intended BITA water-defence axis is held fixed.

Primary common fitness scale:

```text
undamaged mature seed count per focal flower.
```

Required SCH output for Chapter 2:

```text
context_id = population x season x registered protocol
fitness_scale_id = undamaged mature seed count per focal flower
z_P*, z_G*, z_C*
positive causal compromise geometry
bounded fitness-scale conflict load L, when the component-budget gate is met.
```

The independent predator intervention is essential. Water retained/drained must not be reused as SCH antagonist `G` when water defence is the later architecture axis.

## Chapter 2 / BALANCE — middle world

Chapter 2 must first test the architecture ordering directly, before asking BITA to explain it.

Matched states:

```text
shared-world architecture S
= exsertion z under the preregistered baseline water-defence architecture/state used for the SCH receipt

differentiated-accessible world D
= the registered exsertion x x water-defence y architecture experiment, optimized across both axes/states under the same reproductive outcome.
```

Estimate, in the same `context_id` and `fitness_scale_id`:

```text
W_S*
W_D*
Delta_W = W_D*-W_S*.
```

Direct BALANCE support requires the bounded receipt to show:

```text
L > 0
and
Delta_W < 0.
```

If `Delta_W` crosses zero over predator pressure, drought/water context, or another preregistered environment, estimate the direct architecture critical point.

Chapter 2 then reports:

```text
middle-world state
BALANCE width across environment
critical crossing(s)
worldline uncertainty
```

If `s` and `K` are already independently available, `xi`, `d_B`, and `rho` may also be reported. They are not required for the first direct BALANCE receipt.

## Chapter 3 / BITA — differentiated-coordinate world

BITA uses the SCH reference and the matched x-y experiment to test:

```text
R_state = |x0* - z_P*| - |x1* - z_P*|
```

plus preferential functional loading and optimum fitness gain.

BITA then estimates or bounds the decomposition:

```text
s
K
Phi=sL-K
```

and proceeds to mechanism identification where the design permits.

## Cross-check back in BALANCE

After BITA decomposition, Chapter 2 compares:

```text
Delta_W = W_D*-W_S*
Phi     = sL-K

delta_parallel = Delta_W-Phi.
```

Then compare environmental zero crossings:

```text
e_c,direct       from Delta_W(e)=0
e_c,decomposed   from Phi(e)=0.
```

Possible outcomes:

```text
SAME_CRITICAL_POINT
PARALLEL_CRITICAL_POINTS
MULTIPLE_OR_UNMATCHED_CRITICAL_POINTS
NO_CRITICAL_CROSSING.
```

A shifted crossing is not called a biological parallel-world effect until scale, context, cost-definition and omitted-channel audits pass.

## Highest-value experiment

The strongest single experiment programme therefore does not jump from SCH directly to BITA. It deliberately produces three receipts:

```text
1. SCH causal conflict / compromise receipt
2. BALANCE direct two-worldline receipt
3. BITA dimensional-release + mechanism receipt
```

using one population-season, one primary reproductive outcome, and frozen cross-repository identifiers.
