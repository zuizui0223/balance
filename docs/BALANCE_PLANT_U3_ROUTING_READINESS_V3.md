# BALANCE U3 conflict-conditioned routing readiness v3

## Status change

Routing readiness now has an explicit ecological prediction rather than only an
open acquisition target.

The current matched lane establishes three things before any new routing result
is observed:

1. binary pollen-use conflict is not a deterministic separator of heteranthery;
2. visible heteranthery morphology and routing architecture are non-identifying
   proxies in both directions;
3. the remaining conflict-positive routing target, `Senna covesii`, now has a
   frozen directional prediction.

## Bidirectional proxy failure

Among nonheterantherous positive controls:

```text
Solanum lycocarpum  -> AMONG_FLOWER_MODULE_DIVISION
Senna spectabilis  -> WITHIN_FLOWER_DIVISION_OF_LABOUR
```

So the same heteranthery-absent morphology is compatible with at least two
routing states in two dependence blocks.

Conversely:

```text
Senna alata        heteranthery PRESENT -> WITHIN_FLOWER_DIVISION_OF_LABOUR
Senna spectabilis  heteranthery ABSENT  -> WITHIN_FLOWER_DIVISION_OF_LABOUR
```

So the same routing state is compatible with both morphology states.

Therefore:

```text
morphology -> routing   is not deterministic
routing    -> morphology is not deterministic
```

The analysis must retain conflict, routing and morphology as separate variables.

## Frozen Senna covesii prediction

The two resolved positive controls currently give the candidate pattern:

```text
REPEATED_FLOWERS     -> AMONG_FLOWER_MODULE_DIVISION
SERIAL_WITHIN_FLOWER -> WITHIN_FLOWER_DIVISION_OF_LABOUR
```

This is not treated as a general fitted law. Instead it is converted into one
prospective test before the target outcome is available.

`S. covesii` is already:

```text
pollen-fate conflict  POSITIVE
module substrate      SERIAL_WITHIN_FLOWER
routing               UNRESOLVED
```

Frozen prediction:

```text
S. covesii -> WITHIN_FLOWER_DIVISION_OF_LABOUR
```

Adjudication must use the existing `U3MEAS_SENCOV_001` position-resolved
tracking/manipulation plus equivalence contract.

A different resolved architecture falsifies the prediction. An imprecise
`UNRESOLVED` result is inconclusive.

## Dependence ceiling

The prediction is deliberately not called an independent evolutionary
replication. `S. covesii` and the discovery taxon `S. spectabilis` occupy the
same frozen Senna dependence block.

A later independent-block test is still required before treating the
module-routing pattern as a cross-lineage rule.
