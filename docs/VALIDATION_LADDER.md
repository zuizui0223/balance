# BALANCE middle-world validation ladder

## V0 — algebraic / synthetic validation

Required:

- regression tests for the two-sided certificate,
- direct worldline classification,
- direct-versus-decomposed bridge identity under synthetic matched models,
- topology and switching-cost regressions.

Status: implemented.

## V1 — SCH-facing conflict qualification

Required in one biological context:

- common reproductive outcome,
- `L > 0` or a bounded positive conflict budget from SCH,
- context ID frozen before the architecture comparison.

Without this gate, a direct advantage of one architecture is not called a BALANCE result because the registered shared-axis conflict has not been established.

## V2 — direct worldline middle-world receipt

Required in matched contexts:

```text
W_S* = optimized shared-coordinate fitness
W_D* = optimized differentiated-coordinate fitness
```

on one common fitness scale.

BALANCE is directly supported when

```text
L > 0
and
W_D* - W_S* < 0
```

with uncertainty excluding or meaningfully bounding zero.

This route does not require prior estimation of `s` and `K`.

## V3 — decomposed bridge concordance

Estimate or bound

```text
s
K
Phi = sL-K.
```

Compare with

```text
Delta_W = W_D*-W_S*.
```

Registered expectation:

```text
Delta_W = Phi.
```

Report

```text
delta_parallel = Delta_W-Phi.
```

A non-zero residual is a candidate parallel-world shift only after common-scale, context, cost-definition and omitted-channel explanations are audited.

## V4 — domain geometry across environment

Repeat V1/V2 over an ordered environmental axis and estimate:

- BALANCE width,
- `xi`,
- two-sided depth,
- reserve,
- number of intervals,
- direct architecture crossings.

Test the no-reentry sufficient condition against observed topology.

## V5 — history dependence

Measure forward and reverse switching thresholds or use a design that varies context duration `T`.

Test whether the observed persistence band is compatible with

```text
-C_DS/T <= Phi <= C_SD/T.
```

This is the strongest route to an independent Chapter-2 result because it demonstrates behaviour that neither a static SCH optimum nor a static BITA architecture comparison contains by itself.

## Current biological targets

### Pedicularis rex

Role: preferred paired causal chain.

Desired sequence:

```text
SCH causal compromise receipt
-> matched shared-world W_S*
-> controlled second-axis architecture / W_D*
-> direct BALANCE receipt
-> s,K decomposition
-> BITA mechanism allocation.
```

Keep SCH antagonist manipulation independent of the BITA water/defence manipulation to avoid circularly manufacturing the handoff.

### Peucedanum multivittatum

Role: observational critical-region anchor.

The published phenological/predation mosaic and sign changes can motivate an environmental bracket, but they do not by themselves supply matched `W_S*` and `W_D*`. Therefore they cannot by themselves establish V2 BALANCE or a historical architecture transition.

## Claim rule

A lower validation level may motivate the next level but is never silently promoted to a higher one.
