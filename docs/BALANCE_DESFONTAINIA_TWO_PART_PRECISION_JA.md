# BALANCE：*Desfontainia fulgens* の結実2段階・等価性監査（2026年11月16日）

**対象：** Valdivia & Orellana（2026）の公開原本1研究・40株。原本Zenodo DOI [10.5281/zenodo.18895003](https://doi.org/10.5281/zenodo.18895003)、XLSX MD5 `e7e59a06cc3eb7aed636620a85a1ea98`。新たな生物学的反復ではなく、既存のPR #263の検証を追加した。

## 新しい結果

同じ40株から、送粉者あり・盗蜜防止花（+P−R）と、送粉者あり・自然盗蜜花（+P+R）の異なる花を比較した。

| 指標 | 盗蜜防止 | 自然盗蜜 |
| --- | ---: | ---: |
| 種子数が正の花 | 32/40（80%） | 28/40（70%） |
| 種子数が正の花に限る平均 | 32.656粒 | 44.786粒 |
| ゼロも含む平均 | 26.125粒 | 31.350粒 |

株内の差は、増加19・減少19・同数2、中央値0粒。平均差+5.225粒の95%対応t区間は**−12.850〜+23.300粒**。結実あり/なしの非一致ペアは10対6、正確な対称性参照確率0.4545。どちらも「差がない」という証明ではない。

結実確率と、結実した花の種子数という2段階に分けて計算すると、比較対象を基準にした一つの算術的分解では、前者に対応する成分が**−3.266粒**、後者が**+8.491粒**、合計が+5.225粒となる。対応株の20,000回再標本化による95%範囲はそれぞれ**−10.23〜+3.11粒**、**−4.57〜+22.45粒**。**この分解は恒等的な記述であり、送粉補償の因果機構を示さない。** 成功した花だけを選ぶことで選択バイアスも発生する。

## 「盗蜜の害は小さい」と言えるか

平均差の**90%対応t区間は−9.831〜+20.281粒**。保護花の平均26.125粒に対して±10%、±20%、±50%を仮の等価範囲としても、どれにも区間が収まらない。区間を完全に含めるために必要な対称幅は最低でも約**±20.28粒（保護花平均の77.63%）**。これは有意差がないことと、生物学的に小さい差であることが違う、という直接的な精度診断になる。上記の等価範囲は解析後に置いた感度分析で、事前登録されていない。

## 解釈の上限

元の+P+Rは既に穿孔された自然開花花、+P−Rは蕾にテープを巻いた花であり、発育段階・訪花歴・選択・処理効果が混ざっている。花蜜と種子は同一花ではない。従って、種子平均の差や結実2段階の分解から、「盗蜜の因果効果」「補償」「適応度が維持されたこと」を断定してはいけない。雄性適応度、構造的な分業のコスト、同じ条件で最適化した共有形態と分業形態の適応度も未測定である。

**現在支持される結論は、近位資源の大きな損失が観測された一方、種子生産の下流比較は大きな負の差と正の差の両方に整合し、効果が小さいとは証明できない、ということ。**

将来は同発育段階の花を植物内で無作為に、蜜量を減らす操作・穿孔操作・偽操作へ割り当て、同じ花で送粉行動・受精・成熟種子を追う。分業適応度を論じるにはそれとは別に構造的な代替型とコストも必要。
