# BALANCE plant U3 matched-control protocol v1

## Purpose

Convert the Vallejo-Marín et al. (2010) heteranthery-positive family surface into a defensible comparative case-control layer without pretending that the positive-family review is an outcome-blind denominator.

## Case definition

A U3 case is not an entire family. The family registry only identifies a lineage in which heteranthery occurs.

Species-level cases must be promoted separately from a named primary source and must satisfy:

1. species identity resolved;
2. two or more morphologically discrete fertile stamen types within one flower;
3. the heteranthery state documented independently of the BALANCE predictor coding;
4. primary-source provenance frozen.

Families with only Table-S1 representative identities pending cannot yield a species case until the representative source is resolved.

## Comparator target

For each species-level heterantherous case, select one non-heterantherous comparator using the following hierarchy before examining BALANCE predictor values.

### C1 — congeneric sister / nearest available congener

Prefer a non-heterantherous species in the same genus with the closest available phylogenetic relationship.

### C2 — same tribe / subfamily

If no suitable congeneric comparator exists, widen to the nearest documented non-heterantherous relative in the same tribe or subfamily.

### C3 — same family

If C1/C2 fail, use a family-level comparator only with an explicit widening receipt.

Do not jump directly to a convenient ecologically similar species in another family.

## Ecological eligibility

A comparator must retain the biological opportunity for the pollen-fate conflict to be meaningful.

Preferred comparators have animal pollination and pollen use by visitors documented or plausibly present from a primary source.

However, reward type, poricidal anthers, nectary state, enantiostyly, stamen number and pollinator identity must **not** be used as matching variables in the primary U3 comparison because Vallejo-Marín et al. (2010) already identified several of these as heteranthery correlates. Matching on them would block the very variation that later analyses may need to describe.

## Selection blindness

Comparator selection is completed before coding:

- conflict strength;
- pollen-removal intensity;
- module substrate beyond the case-defining stamen state;
- timing/spatial conflict geometry;
- mating-system moderators.

The matching receipt may use only taxonomy/phylogeny, heteranthery absence, source availability and the minimal animal-pollination eligibility rule.

## One case, one primary comparator

The confirmatory matched lane uses one primary comparator per case.

Additional eligible controls can be retained for sensitivity analysis but may not silently increase replication in the main analysis.

If multiple controls are equally close, use a deterministic tie-break:

1. better-resolved phylogenetic distance;
2. primary-source evidence quality;
3. lexicographic taxon name.

## Repeated families

A family may contribute multiple independently sourced species cases only if species-level heteranthery and comparator identities are separately recoverable.

Family and genus random/phylogenetic structure must then be retained. Multiple cases from Fabaceae or Melastomataceae are not treated as independent deep evolutionary origins by default.

## Primary estimand

U3 is a matched comparative lane asking:

> within lineages capable of pollen-reward reproductive biology, which independently measured conflict and architecture attributes distinguish heterantherous structural division from a retained homantherous stamen system?

This is a case-control association estimand, not a prevalence estimand.

## Prior-art exclusion

The primary BALANCE model must not simply re-test the published 2010 family-level result that heteranthery is associated with poricidal anthers, nectar loss and enantiostyly.

Those variables can be used as replication/benchmark checks, but the independent contribution must concern the broader conflict-resolution architecture programme—for example direct pollen-fate conflict evidence, functional coupling, or how serial stamen modules are actually partitioned.

## Freeze gate

No U3 matched analysis is run until:

1. all 16 case families retain verified Figure-2 membership;
2. representative species/source identity is resolved for the intended cases;
3. every primary comparator has a frozen selection receipt;
4. case/control predictor extraction is performed after matching;
5. family/genus dependence is represented;
6. no comparator was selected because it produced the desired predictor contrast.

## Claim ceiling

Even a fully closed U3 matched lane can estimate associations conditional on being sampled from heteranthery-positive families and their matched relatives.

It cannot estimate the prevalence of heteranthery across angiosperms or prove the historical cause of a particular transition.
