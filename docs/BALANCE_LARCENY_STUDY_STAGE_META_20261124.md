# Floral larceny: exploratory paper-level stage meta-analysis

2026-11-24; stacked on PR #267; all source stages, not positive cases only. This is post-publication reanalysis, not a new prospective experiment. The first question is whether the difference in archived lnRR between seed set and fruit set persists when both are reported within the same paper, species and all archived context fields. This is NOT same-treatment or cohort confirmation. Unknown/missing context fields can match mechanically. Distinct endpoints have nonstandardized biological denominators.

Primary contrast: seed set minus fruit set, exact archive context. Secondary: looser paper-species and exact one-to-one context contrasts; three adjacent stage contrasts; five marginal stage meta-analyses. All effect directions included. Each paper contributes at most one summary per analysis: average effects equally within endpoint arms, average eligible species-context contrasts equally within paper. Each paper is a provisional study cluster, not proof of independence across publications; phylogenetic dependence unmodeled. Marginal stages need not include same papers.

Given linear summary coefficients c_i, use working variance sum(c_i^2 v_i) under independence, and the Cauchy upper bound (sum(abs(c_i) sqrt(v_i)))^2 under arbitrary within-paper covariance. Interpolate the two at 0, 0.5, 1 as working variance scenarios (NOT estimated correlations or guaranteed inferential coverage). Estimate between-paper heterogeneity by DL and modified Knapp-Hartung intervals; minimum 5 papers, no outcome-dependent choice of covariance scenario. Report equal-paper means and every directional count. Nominal unadjusted intervals; no significance gate. Secondary moderator screens for pollen limitation, self compatibility and damage use unmodified nonmissing archive labels, with one unambiguous level per paper and at least five papers per level; two-level contrasts only. These are not adjusted causal moderator estimates. No merging of Zhong and Leal. No changes to frozen U2/U6/V4 or architecture codes.

The workflow authenticates the original ZIP and XLSX, runs source and synthetic regression tests and publishes all paper-level contrasts and fit summaries. Numerical results are pending successful source run; no novel biological effect or direct structural BALANCE occupancy asserted by the implementation alone.
