# Peucedanum observational critical-region anchor v1

## Role in Chapter 2

`Peucedanum multivittatum` is an observational anchor for the existence of a context-dependent critical region. It is **not** yet a direct SCH→BALANCE→BITA architecture-worldline receipt.

The ordered contexts are:

```text
HA -> HL -> HC -> KD -> HD
```

Three published operational definitions change regime in the same coarse interval:

```text
final fruit-set selection gradient beta:   HL -0.029 -> HC +0.034
final fruit-set selection differential S:  HL -0.051 -> HC +0.036
female-gain exponent minus one:             HL -0.55  -> HC +0.15
```

The registered Chapter-2 classification is therefore:

```text
SAME_COARSE_CRITICAL_BRACKET
common bracket = HL--HC.
```

This supports the statement that multiple independent definitions point to one observational transition region.

## Conditional numeric proxy

Published mean predator eggs per umbel are:

```text
HL = 3.09
HC = 1.64.
```

Under an explicitly conditional local-linear interpolation between only these two contexts, the three definition-specific zero crossings are approximately:

```text
beta       2.423 eggs/umbel
S          2.240 eggs/umbel
b-1        1.951 eggs/umbel.
```

These point estimates are not identical. They therefore must not be represented as a directly observed universal numeric critical point.

## What this anchor does and does not establish

It supports:

```text
multiple definitions -> one coarse observational critical region.
```

It does not establish:

```text
L > 0 on the SCH fitness scale;
W_S* or W_D*;
BALANCE middle-world occupancy;
Phi = sL-K;
a common SCH/BITA architecture crossing;
predator eggs per umbel = theoretical functional weight;
historical trait splitting.
```

The stronger architecture-worldline test remains the matched-receipt programme in issue #3, with `Pedicularis rex` as the preferred same-species causal route.
