# BALANCE heteranthery boundary recovery v1

## Purpose

Close the first `BOUNDARY_CROSSING` row in the Chapter-2 reality-pattern ledger without importing population coexistence or pretending that a phylogenetic transition is a direct worldline threshold.

The target is heteranthery: functional differentiation of stamens within the same flower into pollen-reward and pollen-export roles.

## Biological conflict

In pollen-rewarding flowers the same pollen has two competing fates:

```text
reward consumed by pollen-collecting pollinators
vs
gametes exported for cross-fertilization
```

This is a genuine shared-resource conflict. If more pollen is consumed to maintain visitation fewer male gametes remain available for export.

## Experimental functional evidence

Vallejo-Marín et al. (2009; Journal of Evolutionary Biology; DOI 10.1111/j.1420-9101.2009.01693.x) experimentally tested the division-of-labour hypothesis in `Solanum rostratum`.

The same flower contains:

```text
feeding anthers
-> preferentially manipulated by bumble bees
-> primarily support the pollen-reward function

pollinating anther
-> exports more pollen to stigmas of other flowers
-> primarily supports male reproductive transfer
```

Thus the differentiated architecture is not inferred only from morphology: the two stamen types have experimentally distinct functional loading.

## Shared-to-differentiated transition evidence

Most `Solanum` species have approximately equal stamens. Phylogenetic syntheses reviewed by Vallejo-Marín et al. (2010; New Phytologist; DOI 10.1111/j.1469-8137.2010.03430.x) show repeated independent origins of heteranthery within the genus, including multiple origins within the spiny solanums.

For the focal Solanum context the phylogenetic ordering is especially useful:

```text
pollen-only floral reward / no nectary
+
buzz pollination / poricidal anthers
-> precede repeated origins of heteranthery
```

The shared state is therefore represented by approximately isomorphic stamens that jointly carry the two pollen functions, whereas the differentiated state partitions those functions among feeding and pollinating anthers.

Registered R-layer class:

```text
BOUNDARY_CROSSING
```

## Why this is a BALANCE boundary pattern

The repository definition of `BOUNDARY_CROSSING` is evidence for a transition from a shared to a differentiated state as biological context changes. It does not require a direct same-scale `W_S* / W_D*` comparison; that stronger requirement belongs to the final causal/worldline layer.

Heteranthery satisfies the pattern-level object because:

1. the conflict is biologically explicit;
2. the ancestral/common architecture keeps the competing functions on similar stamens;
3. the alternative architecture partitions the two functions within one flower;
4. the functional partition is experimentally verified;
5. phylogenetic evidence recovers repeated transitions into that differentiated architecture in the relevant pollination background.

This differs categorically from an ecological population splitting into two specialist subpopulations. The latter is a PAYOFF-like coexistence object and remains excluded from the BALANCE boundary count.

## Robustness / non-universality check

Heteranthery is evolutionarily labile outside the focal Solanum case. Comparative work in Merianieae reports repeated gains and reversals and shows that heteranthery can occur with pollen, food-body, or nectar rewards.

Therefore:

```text
absence of nectar / buzz pollination
!= universal sufficient condition for heteranthery
```

and a phylogenetic reversal from heteranthery to isomorphic stamens is **not** registered as BALANCE hysteresis. Hysteresis requires forward/reverse state dependence under a comparable control path rather than historical gain and loss on different branches.
