# Morph-dependent female stage contrasts: Tirpitzia sinensis (2026-11-26)

Wang et al. 2023, Ecology and Evolution 13:e10714, DOI 10.1002/ece3.10714, full text https://pmc.ncbi.nlm.nih.gov/articles/PMC10638493/. Original Dryad 10.5061/dryad.6hdr7sr62. Separate from Ipomopsis, but already represented in Zhong 2025 (ref-ID 104); do not double count. A new reanalysis of the printed morph-specific points, not discovery of the original treatment effects. Same intermorph hand-pollination treatment design with C (undamaged), H (artificial hole) and N (nectar removal without intentional injury). Germination fraction, not deposition count; destructive pistils collected after 6h, about 25 plants/morph, three buds randomly allocated. Seed experiment 50 plants/morph initially, lost material, >20 samples per treatment, measured fertilized / (fertilized + unfertilized seeds). Different flowers and uncertain cross-experiment plant linkage. Seed fraction not all allocated flowers. Use original morph-specific values, never square or otherwise transform reported percentages. Original text claims significant germination treatment×morph interaction but Table 2 p=.931; seed interaction table p=.036. Report discrepancy, do not interpret significant vs nonsignificant results as interaction.

Contrast Δ = lnRR(seed fraction) − lnRR(germination fraction). L: H -.51697, N -.35589; S: H +.21583, N +.31631. L−S stage difference H -.73280, N -.67221; report both normal working independence and Cauchy maximal covariance intervals. Shared control and unknown dependence; first-order intervals assume validity of printed SE, no exact or confirmatory inference. Do not call morph contrast established if conservative intervals cross zero. Natural visitation contrast has different exposure (natural robbing), observational context, separate endpoint data; kept separate. Source code authenticates original Zhong XLSX before matching reported ratios to original archive rows, no silent label correction. Source recovery uses official Dryad metadata and exact MD5/size for public mirror, bounded, no bypass. Heiling pinned original file retry; no claim of raw data without verified bytes. Tecoma 2024 has only nectar and visitation; Digitalis 2022 pollen export is male; neither supplies a female germination-to-seed contrast. Symphytum 2021 (10.3390/biology10090903) reports delayed selfing enabled by corolla abscission, but Table 2 and prose disagree in seed figures/units; not a matched raw-data contrast here. No V4 or structural changes.
