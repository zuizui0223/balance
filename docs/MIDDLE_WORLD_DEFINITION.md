# BALANCE as the middle world between SCH and SLK

## 1. Programme-level interpretation

The linked repositories describe different inferential layers of one trait-architecture problem rather than a single linear chapter sequence.

```text
SCH
shared-coordinate architecture
-> identify whether functions are in causal conflict and export conflict load L

BALANCE
shared-coordinate conflict is real
but the best registered differentiated-accessible worldline still loses
-> characterize the geometry, depth, topology, and persistence of that middle world

SLK
architecture value and evolutionary transport
-> define Phi = R-K, then separate global value from accessibility, invasion,
   fixation, and occupancy

BITA
trait-interaction mechanism identification
-> ask what an observed A x D interaction identifies and which ecological
   channels can be allocated by selective intervention
```

BALANCE is therefore a **sandwiched architecture-value world** bounded by SCH and SLK. BITA is orthogonal: it can explain ecological channel allocation without owning the architecture-value boundary.

## 2. Complementary inequalities

Let

```text
L   = fitness-scale conflict / compromise load inherited from SCH
R   = recoverable conflict loss for the registered differentiated architecture
K   = additional architecture cost on the same fitness scale
Phi = R-K
```

The SCH-facing certificate is

```text
L > 0.
```

The SLK-facing architecture-value certificate is

```text
Phi > 0
```

for the differentiated architecture to have higher optimized value.

The BALANCE world is the complementary intersection

```text
L > 0
and
Phi < 0.
```

Under the registered quadratic bridge only,

```text
R = sL,  s in [0,1],
```

so when `s>0`, BALANCE can be written

```text
0 < L < K/s.
```

`R=sL` is a model-specific bridge/corollary, not the general definition of recoverable benefit.

Thus BALANCE is neither "no conflict" nor "failed differentiation". It is the region in which conflict is biologically real but remaining on one coordinate still has higher optimized architecture value.

## 3. Two-sided coordinates inside BALANCE

Define the SLK-facing architecture reserve

```text
rho = K-R = -Phi > 0.
```

Then a BALANCE point has two distances in the common fitness units:

```text
SCH-facing distance = L
SLK-facing distance = rho.
```

This motivates two Chapter-2 estimands.

### 3.1 Middle-world position

```text
xi = L / (L + rho).
```

Inside BALANCE,

```text
0 < xi < 1.
```

Interpretation:

```text
xi -> 0   close to the SCH-facing no-conflict boundary
xi ~ 0.5  centred between the two boundaries in the common fitness units
xi -> 1   close to the SLK-facing architecture-value boundary.
```

`xi` is not an evolutionary time variable. It is a location inside the present-day architecture-state geometry.

### 3.2 Two-sided depth

```text
d_B = min(L, rho).
```

This is the minimum fitness-scale distance to either bounding surface when perturbing one registered margin at a time. Large `d_B` identifies contexts that are deeply inside the BALANCE world rather than merely unresolved near one boundary.

## 4. Static core versus dynamic persistence halo

The **static BALANCE core** is

```text
L > 0 and Phi < 0.
```

Switching costs create a wider **persistence halo**. If shared -> differentiated switching costs `C_SD`, differentiated -> shared costs `C_DS`, and the context persists for horizon `T`, then

```text
-C_DS/T <= Phi <= C_SD/T
```

is history dependent.

Therefore a lineage starting in the shared architecture can persist temporarily even for small positive `Phi`, while a lineage already differentiated can persist for small negative `Phi`.

This makes BALANCE genuinely about persistence and state history, not only about a static inequality. It still does not by itself identify accessibility, invasion, fixation, or occupancy; those are SLK transport questions.

## 5. What would make BALANCE scientifically independent?

BALANCE earns independence from SCH and SLK if at least one of these is recovered empirically:

1. **Domain geometry:** natural contexts differ predictably in `xi`, `d_B`, BALANCE width, or integrated reserve.
2. **Topology:** re-entry or multiple BALANCE intervals occur and can be attributed to non-monotone `L`, `R`, or `K` rather than measurement noise.
3. **History dependence:** forward and reverse architecture thresholds differ as predicted by switching costs and context duration.
4. **Comparative prediction:** BALANCE metrics predict which systems remain integrated versus which cross the architecture-value boundary better than conflict magnitude alone.

## 6. Relation to BITA

BITA does not define the `Phi=0` boundary. Its active object is a trait-interaction estimand such as

```text
Delta_AD W
```

and the identified set of ecological channel allocations compatible with that total interaction. A BITA mechanism decomposition may inform biological interpretation of recoverable benefit or costs only when an explicit bridge is justified; it is not algebraically identical to `R`, `K`, or `Phi` by default.

## 7. Claim ceiling

Do not infer from a BALANCE-domain estimate alone that:

- historical trait splitting occurred,
- a lineage is evolving toward differentiation,
- `K` is a historical developmental cost unless it was measured as such,
- state-specific SCH optima equal pure function optima,
- present-day re-entry proves macroevolutionary reversibility,
- a BITA ecological channel has been identified,
- `Phi>0` implies accessibility, invasion, fixation, or occupancy.

The repository studies the ecology and dynamics of the **interior region between the SCH conflict boundary and the SLK architecture-value boundary**.
