# BALANCE as the middle world between SCH and BITA

## 1. Programme-level interpretation

The three repositories are not three unrelated theories.

They describe three adjacent states of one trait-architecture problem:

```text
SCH world
shared-coordinate architecture
-> ask whether two functions are in causal conflict and where the shared optimum settles

BALANCE world
shared-coordinate conflict is real
but the recoverable benefit of extra dimensionality is still below its cost
-> ask how large, deep, connected, persistent, and history-dependent this region is

BITA world
differentiated architecture is worth paying for
-> ask how much conflict is released and which ecological pathway causes the gain
```

BALANCE is therefore deliberately treated as a **sandwiched world**. It is defined from both sister chapters rather than by inventing an unrelated third fitness function.

## 2. Complementary inequalities

Let

```text
L   = fitness-scale conflict / compromise load inherited from SCH
s   = fraction of L recoverable by additional dimensionality
R   = sL
K   = additional architecture cost inherited from the BITA comparison
Phi = R-K
```

The SCH-facing certificate is

```text
L > 0.
```

The BITA-facing certificate is

```text
Phi > 0
```

for differentiation to be favoured.

The BALANCE world is the complementary intersection

```text
L > 0
and
Phi < 0.
```

Equivalently,

```text
0 < L < K/s
```

when `s > 0`.

Thus BALANCE is neither "no conflict" nor "failed differentiation". It is the region in which conflict is already biologically real but remaining on one coordinate is still the better architecture.

## 3. Two-sided coordinates inside BALANCE

Define the BITA-facing reserve

```text
rho = K-R = K-sL > 0.
```

Then a BALANCE point has two distances in the common fitness units:

```text
SCH-facing distance  = L
BITA-facing distance = rho.
```

This motivates two Chapter-2 estimands.

### 3.1 Middle-world position

```text
xi = L / (L + rho).
```

Inside BALANCE,

```text
0 < xi < 1.
```

Interpretation:

```text
xi -> 0   close to the SCH-facing no-conflict boundary
xi ~ 0.5  centred between the two boundaries in the common fitness units
xi -> 1   close to the BITA-facing differentiation boundary.
```

`xi` is not an evolutionary time variable. It is a location inside the present-day architecture-state geometry.

### 3.2 Two-sided depth

```text
d_B = min(L, rho).
```

This is the minimum fitness-scale distance to either bounding surface when perturbing one registered margin at a time. Large `d_B` identifies contexts that are deeply inside the BALANCE world rather than merely unresolved near one boundary.

## 4. Static core versus dynamic persistence halo

The **static BALANCE core** is

```text
L > 0 and Phi < 0.
```

Switching costs create a wider **persistence halo**. If shared -> differentiated switching costs `C_SD`, differentiated -> shared costs `C_DS`, and the context persists for horizon `T`, then

```text
-C_DS/T <= Phi <= C_SD/T
```

is history dependent.

Therefore a lineage starting in the shared architecture can persist temporarily even for small positive `Phi`, while a lineage already differentiated can persist for small negative `Phi`.

This makes the middle chapter genuinely about persistence and state history, not only about a static inequality.

## 5. What would make BALANCE scientifically independent?

Chapter 2 earns independence from SCH and BITA if at least one of these is recovered empirically:

1. **Domain geometry:** natural contexts differ predictably in `xi`, `d_B`, BALANCE width, or integrated reserve.
2. **Topology:** re-entry or multiple BALANCE intervals occur and can be attributed to non-monotone `L`, `s`, or `K` rather than measurement noise.
3. **History dependence:** forward and reverse architecture thresholds differ as predicted by switching costs and context duration.
4. **Comparative prediction:** BALANCE metrics predict which systems remain integrated versus which cross into differentiated architecture better than conflict magnitude alone.

## 6. Claim ceiling

Do not infer from a BALANCE-domain estimate alone that:

- historical trait splitting occurred,
- a lineage is evolving toward differentiation,
- `K` is a historical developmental cost unless it was measured as such,
- state-specific SCH optima equal pure function optima,
- present-day re-entry proves macroevolutionary reversibility.

The repository studies the ecology and dynamics of the **interior region between the two sister-chapter boundaries**.
