# BALANCE as the middle world between SCH and SLK

## 1. Programme-level interpretation

The linked repositories describe different inferential layers of one trait-architecture problem rather than a single linear chapter sequence.

```text
SCH
shared-coordinate architecture
-> identify whether functions are in causal conflict and export conflict load L

BALANCE
shared-coordinate conflict is real
but the best registered differentiated-accessible worldline still loses
-> characterize the geometry, depth, topology, and persistence of that middle world

SLK
architecture value and evolutionary transport
-> define Phi = R-K, then separate global value from accessibility, invasion,
   fixation, and occupancy

BITA
trait-interaction mechanism identification
-> ask what an observed A x D interaction identifies and which ecological
   channels can be allocated by selective intervention
```

BALANCE is therefore a **sandwiched architecture-value world** bounded by SCH and SLK. BITA is orthogonal: it can explain ecological channel allocation without owning the architecture-value boundary.

## 2. Complementary inequalities

Let

```text
L   = fitness-scale conflict / compromise load inherited from SCH
R   = recoverable conflict loss for the registered differentiated architecture
K   = additional architecture cost on the same fitness scale
Phi = R-K
```

The SCH-facing certificate is `L>0`. The SLK-facing architecture-value certificate is `Phi>0` for the differentiated architecture to have higher optimized value. The BALANCE world is

```text
L > 0
and
Phi < 0.
```

Under the registered quadratic bridge only,

```text
R = sL,  s in [0,1],
```

so when `s>0`, BALANCE can be written `0<L<K/s`. `R=sL` is a model-specific bridge/corollary, not the general definition of recoverable benefit.

## 3. Two-sided coordinates inside BALANCE

Define the SLK-facing architecture reserve

```text
rho = K-R = -Phi > 0.
```

A BALANCE point has SCH-facing distance `L` and SLK-facing distance `rho` in common fitness units. Define

```text
xi = L/(L+rho)
d_B = min(L,rho).
```

Inside BALANCE, `0<xi<1`; `xi->0` approaches the SCH-facing no-conflict boundary and `xi->1` approaches the SLK-facing architecture-value boundary. `xi` is not evolutionary time.

## 4. Static core versus dynamic persistence halo

The static BALANCE core is `L>0 and Phi<0`. Switching costs can create a wider history-dependent persistence halo around `Phi=0`, but this does not by itself identify accessibility, invasion, fixation, or occupancy; those are SLK transport questions.

## 5. Relation to BITA

BITA does not define the `Phi=0` boundary. Its active object is a trait-interaction estimand such as `Delta_AD W` and the identified set of ecological channel allocations compatible with that total interaction. A BITA mechanism decomposition may inform biological interpretation of recoverable benefit or costs only when an explicit bridge is justified; it is not algebraically identical to `R`, `K`, or `Phi` by default.

## 6. Claim ceiling

Do not infer from a BALANCE-domain estimate alone that historical trait splitting occurred, that a lineage is evolving toward differentiation, that a BITA ecological channel has been identified, or that `Phi>0` implies accessibility, invasion, fixation, or occupancy.

The repository studies the ecology and dynamics of the **interior region between the SCH conflict boundary and the SLK architecture-value boundary**.
