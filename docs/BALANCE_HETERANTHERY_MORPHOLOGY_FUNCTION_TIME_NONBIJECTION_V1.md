# Floral heteranthery is not one ecological architecture: original-source mechanism crosscheck V1

Date: 2026-10-21. **Status: source-verified comparison of pre-existing original-study extracts, not a new raw-data experiment, representative macro-sample, independent dated evolutionary transition, or direct SLK G1–G5 receipt.**

## Most important result

**The same visible two-anther phenotype has at least two experimentally investigated ecological interpretations.** The existing BALANCE U3 source screen identifies within-flower feeding-anther versus pollen-export functional separation in *Solanum rostratum* (Vallejo-Marín et al. 2009). Kay et al. (2020, *Proc. R. Soc. B* 287:20202593, DOI [10.1098/rspb.2020.2593](https://doi.org/10.1098/rspb.2020.2593)) instead find evidence supporting **delayed/gradual pollen presentation** in visibly heterantherous *Clarkia* spp., while their tested *C. cylindrica* inner/outer whorl pollen appears on both bee scopae and floral stigmas.

**Reverse mismatch:** visibly nonheterantherous *Senna spectabilis* still shows within-flower pollen-fate routing, while nonheterantherous *Solanum lycocarpum* uses different function allocation **among flowers**. Thus (i) different function mechanisms can underlie the *same morphology*, and (ii) the same source-tested function routing can occur with *different morphologies*.

These are constructive counterexamples to identifying **functional structural modules** by counting unequal stamen morphs across angiosperms.

## New conceptual distinction required by the data

The existing three-way SLK comparator (static shared phenotype; **reversible cue-dependent** plasticity; permanently differentiated coexpressed function modules) covers some mathematical mechanisms, but **not every botanical strategy**.

Anatomically distinct floral organs can implement at least two different architectural functions:

1. **`IN_PARALLEL_ROLE_PARTITION`** — distinct organs are adapted to *different biological functions* in the same ecological window (pollen provision versus pollen export);
2. **`IN_SERIES_TEMPORAL_RESERVOIR`** — distinct organs both provide broadly similar types of pollen functionality, but one stores and presents it **later**.

The latter need not be a *cue-reversible shared scalar state*, either: release may be programmed by flower age/development and cannot be reversed within the same mature flower. Conversely, some temporal shifts can be reversible plastic programmes. **Do not merge** these without an independent reversibility assay.

Therefore macro floral-trait coding should cross **anatomical differentiation × ecological function-route segregation × time of exposure × reversibility**, rather than use a binary 'heteranthery' column as the differentiating architecture outcome.

To test the strong central evolutionary question, the next empirical question is **not** whether two anther types exist. It is whether a verified conflict in a *specific functional coordinate* made new organs with specified route/timing properties yield larger net reproductive fitness than viable shared, reversible and other temporally programmed alternatives—and whether the resulting new heritable architecture subsequently arose.

## Separate conflict-first check: visitor chronology is not floral pollen-dosing architecture

BALANCE also has the [frozen 21-group U6 consumptive-emasculation source universe](https://github.com/zuizui0223/balance/blob/audit/u6-preoutcome-taxonomy-20261021/docs/BALANCE_U6_SOURCE_OPPORTUNITY_AND_TAXON_ALIAS_AUDIT_V1.md), admitted by pollen-theft evidence before any morphology coding. In this upstream source screen, the source pollen pool is one common unit in 21/21 cases and original conflict timing is coded simultaneous in 18, sequential in three: *Clusia arrudae*, *Crescentia alata*, and *Tolmiea menziesii*. These **three source-ordered visitor arrivals do not establish scheduled anther opening**, do not demonstrate a genetically acquired temporal pollen reservoir and cannot be counted as replicated Clarkia-type floral ontogenies.

All 42 U6 independent architecture coding slots remain unstarted, so adding U6 cannot yet measure whether the directly screened pollen-theft systems exhibit shared, timed, or structurally divided anthers. Conversely, the present outcome-selected Clarkia/U3 10-taxon table must never be injected to fill the U6 missing response states. Canonical U6 taxonomy includes a held *Melastoma affine*–*M. malabathricum* accepted-species overlap with U3 (plus the *Impatiens capensis* U1 exact-species overlap); cross-study species independence must be audited before interpreting any new comparative association.
