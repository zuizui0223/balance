# Three-chapter contract v1 — BALANCE

## Position

```text
Chapter 1 / SCH      shared-coordinate compromise
Chapter 2 / BALANCE  persistence inside the compromise regime
Chapter 3 / BITA     differentiated architecture and mechanism
```

BALANCE is not a renamed subsection of SCH or BITA. It owns the regime

```text
L(e) > 0
Phi(e)=s(e)L(e)-K(e) < 0
```

where conflict is real but differentiation is not yet worth its cost.

## Inputs

From SCH, preferably on a common fitness scale:

```text
L(e) = compromise/conflict load
```

From BITA or a paired architecture assay:

```text
s(e) = recoverable fraction / effective decoupling
K(e) = added architecture cost
```

## Primary Chapter-2 questions

1. How wide is the BALANCE domain in environmental and fitness space?
2. How much reserve `rho=K-sL` remains before differentiation becomes favourable?
3. Is BALANCE one connected interval or multiple/re-entrant domains?
4. Under explicit switching costs, how long can architecture history persist after instantaneous fitness ordering changes?
5. Do `q=R/K`, reserve, width, or topology predict which real systems remain multifunctional versus differentiated?

## Outputs to BITA

Chapter 2 supplies the architecture boundary `Phi=0`, domain geometry, and persistence context. BITA then asks whether differentiated axes beyond that boundary actually release the SCH compromise and by what mechanism.

## Independence gate

The chapter is scientifically independent only if it contributes domain-level or dynamic results beyond the entry inequality `0<L<K/s`. The current minimum independent results are the monotone no-reentry condition and explicit switching-cost hysteresis model.
