## Retrieval order

The next literature expansion should target the missing BALANCE-specific signatures rather than simply importing every SCH conflict case.

1. direct persistence cases: conflict active while a plausible alternative architecture exists but the integrated/shared state persists;
2. environmental boundary crossings: the same system moves between integrated, transition, and differentiated-compatible regimes along a measured context axis;
3. path dependence or hysteresis: forward and reverse transitions differ, or state occupancy depends on prior context duration/history;
4. transition mosaics: replicated space/time systems where selection or architecture state reverses across the same ordered context;
5. no-BALANCE controls: aligned-function systems or monotonic systems where an interior regime is not expected.

## Minimum metadata

Every admitted cluster should preserve:

`cluster_id`, source identity, taxon/domain, conflict state, shared-architecture state, alternative-architecture state, pattern class, context axis, evidence level, confidence, quantitative compatibility, source basis, and claim ceiling.

## Quantitative rule

Do not pool unmatched studies into `s`, `K`, `Phi`, `rho`, `xi`, or `d_B`. Compatible transition thresholds or occupancy effects may be synthesized only within a preregistered common construct. Otherwise recurrence, topology, moderator structure, and boundary cases are the empirical targets.

## Final experimental layer

A focal direct `W_S*` versus `W_D*` worldline experiment is the last identification upgrade. It should be chosen after the synthesis identifies which BALANCE-specific gap remains decisive, not treated as the primary empirical entry point.
