# BALANCE quantitative meta-analysis promotion rule v1

## Purpose

BALANCE asks whether conflict can remain while an integrated/shared architecture still outranks an accessible differentiated alternative. The first empirical layer is recurrence of persistence, transition, boundary, and path-dependence signatures. Numerical pooling is allowed only when architecture states are measured on a common performance or fitness scale.

## Strict architecture-effect lane

A study may enter the strict quantitative BALANCE lane only when, within the same biological system and declared context, it contains:

1. an integrated/shared architecture state;
2. an accessible within-unit differentiated/alternative architecture state;
3. the same registered outcome or fitness scale for both states;
4. an estimable architecture contrast and valid uncertainty;
5. enough context information to know which architecture is favoured.

Historical endpoint comparisons, cross-species deletion comparisons, fluorescence-only objective trade-offs, and population-level coexistence/specialist mixtures may be useful pattern evidence but do not automatically enter this lane.

## Boundary-crossing lane

A quantitative boundary claim additionally requires the ordering of the same two architecture states to change across a declared environmental, resource, cost, or coupling axis. Separate studies of an integrated state in one system and a differentiated state in another do not identify a BALANCE boundary.

## Hysteresis lane

A strict hysteresis claim requires forward and reverse traversal of the same registered control variable, or an equivalent design that identifies distinct state-switch thresholds. Generic historical contingency or an evolutionary reversal experiment without the same control axis remains an analogue only.

## Random-effects promotion gate

A pooled architecture effect is calculated only if all are true:

```text
independent biological clusters >= 3
same architecture contrast family
common or validly transformed outcome scale
valid standard error / sampling variance
no duplicate lineage or experimental panel counted twice
```

No grand mean is created from rows that differ only semantically but not statistically comparably.

## Current implication

The current candidate universe contains controlled persistence, direct differentiation, boundary-compatible systems, and a cross-domain hysteresis analogue, but zero rows yet satisfy the full common-scale shared-vs-alternative architecture-effect contract. This zero is an identification result, not a missing-data value to be imputed.

## Claim ceiling

Pattern recurrence can support that conflict-without-splitting, persistence, transitions, and differentiated outcomes all occur. Until the strict worldline contrast exists, the literature synthesis cannot estimate the BALANCE net architecture gap or a universal critical threshold.

## Focal experiment position

A matched shared-vs-alternative architecture worldline experiment is therefore the final identification upgrade after systematic pattern recovery, not the empirical entry point.
