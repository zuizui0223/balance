# BALANCE adjacent quantitative lanes readout v1

## Current structure

The strict positive Q1B pool remains frozen at three independent biological clusters: Fragaria, Impatiens, and Gymnadenia. Adjacent evidence is retained in separate estimand lanes rather than used to inflate the Q1B numerator.

## Adjacent lanes

### Sequential-filter lane

Campbell et al. 2022 / Ipomopsis is retained as a sequential female-fitness decomposition. Corolla width shows strong pollination-stage selection while seed-predation selection is not detected in the same dataset. This is useful as a boundary/control for where shared-coordinate conflict fails to recur, but it is not the same 2x2 factorial Q1B estimand.

### Discrete-morph lane

Agren et al. 2013 / Primula farinosa provides strict opposing selection on a genetically based long-versus-short scape morph: pollinators favor the long morph while grazers favor the short morph. This supports a selection-mosaic boundary but must remain on a relative-fitness morph estimand and must not be converted to a continuous standardized beta.

### Design-matched negative controls

Santangelo et al. 2018 / Trifolium repens is retained as a public-data factorial negative control because pollination did not independently alter selection on the same trait coordinate in the registered analysis.

Thomsen & Sargent 2017 / Lythrum salicaria is an effect-ready source-reported negative control. Pollinator-mediated delta-beta values are -0.01 +/- 0.05, 0.00 +/- 0.06, and -0.07 +/- 0.06 across the registered traits; pollination x damage x trait contrasts are -0.12 +/- 0.12, 0.11 +/- 0.13, and 0.01 +/- 0.12. These near-null values constrain any claim that opposing-agent conflict is inevitable.

### Attribution-boundary lane

Chapurlat et al. 2019 / Gymnadenia conopsea contains pollinator versus residual nonpollinator opposition for scent compounds, but the focal population lacks support for an antagonist mechanism. It is therefore retained as an attribution failure, not as antagonist-mediated Q1B evidence.

## Interpretation

The empirical architecture is now intentionally layered:

1. strict Q1B positives quantify replicated opposing-agent selection under a common factorial estimand;
2. design-matched negative controls test specificity;
3. sequential and discrete-morph lanes test nearby but non-identical manifestations of conflict;
4. attribution failures show that statistical opposition alone is insufficient for biological mechanism assignment.

This layered structure supports a stronger reality-pattern claim than a positive-only pool while preserving the theory-to-data identification boundaries.
